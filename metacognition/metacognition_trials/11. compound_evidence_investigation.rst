Scenario 11: Compound Investigation Blueprint with Sub-Blueprint Evidence Delegation
=====================================================================================

This trial demonstrates a compound parent blueprint (``Firefighting Robotics Sensor Investigation``)
delegating literature research to the ``Evidence Extractor`` sub-blueprint and accumulating verified findings
into the shared Conversation State Tree.

It highlights:
1. **Sub-Blueprint Delegation**: The parent graph pauses its execution and delegates the focal research question to the canonical ``Evidence Extractor`` child blueprint.
2. **Deterministic-to-LLM Hybrid Pipeline**: Inside the child blueprint, Step 1 performs deterministic ``pure_tool`` retrieval, and Step 2 extracts cited findings.
3. **State-Tree Fact Accumulation**: Upon completion, ``_merge_state_trees`` automatically bubbles the child's ``established_facts`` up into the parent conversation's working memory map.
4. **Grounded Downstream Synthesis**: Downstream reasoning nodes in the parent blueprint immediately receive the accumulated facts in their prompt context without re-querying the database.

Setup & Database Seeding
------------------------
We initialize the canonical ``Evidence Extractor`` and construct a parent ``Sensor Investigation`` blueprint.

    >>> from django.contrib.auth.models import User
    >>> from background_resources.models import RAGChunk
    >>> from llm_api.apps import service_registry
    >>> from llm_api.models import Conversation
    >>> from metacognition.models import CognitiveBlueprint, ReasoningStep, ToolDefinition
    >>> from metacognition.seed import seed_evidence_extractor, seed_tools
    >>> from metacognition.tasks import run_blueprint
    >>> import contextlib, io

    >>> user, _ = User.objects.get_or_create(username="compound_evidence_user")
    >>> seed_tools(ToolDefinition)
    >>> seed_evidence_extractor(CognitiveBlueprint, ReasoningStep, ToolDefinition)
    >>> child_bp = CognitiveBlueprint.objects.get(name="Evidence Extractor")

    >>> # Build Parent Blueprint
    >>> parent_bp, _ = CognitiveBlueprint.objects.update_or_create(
    ...     name="Firefighting Sensor Investigation",
    ...     defaults={
    ...         "description": "Investigates robot sensor configurations and synthesizes empirical recommendations.",
    ...         "is_autonomous": True
    ...     }
    ... )
    >>> _ = ReasoningStep.objects.filter(blueprint=parent_bp).delete()

    >>> # Step 1: Delegate to Evidence Extractor child blueprint
    >>> step_sub = ReasoningStep.objects.create(
    ...     blueprint=parent_bp,
    ...     name="Delegate Evidence Extraction",
    ...     is_start_node=True,
    ...     sub_blueprint=child_bp,
    ...     system_prompt="Extract verified empirical findings on sensor resilience in dense smoke."
    ... )

    >>> # Step 2: Synthesize Robot Architecture from accumulated established_facts
    >>> step_synth = ReasoningStep.objects.create(
    ...     blueprint=parent_bp,
    ...     name="Synthesize Robot Architecture",
    ...     execution_mode="llm",
    ...     include_state_tree=True,
    ...     system_prompt=(
    ...         "You are a Chief Robotics Engineer.\n"
    ...         "Examine the verified established_facts in your Conversation State Tree.\n"
    ...         "Synthesize a sensor suite specification for an autonomous urban firefighting robot. "
    ...         "Explicitly ground your choice in the empirical citations provided."
    ...     )
    ... )
    >>> step_sub.on_success_step = step_synth
    >>> step_sub.save()

Seeding Empirical Literature Chunk
----------------------------------
We seed a concrete ``RAGChunk`` entry in Postgres so the child ``Evidence Extractor`` retrieves real database evidence live.

    >>> _ = RAGChunk.objects.filter(chunk_id="trial11-radar").delete()
    >>> c_radar = RAGChunk.objects.create(
    ...     chunk_id="trial11-radar",
    ...     text_content=(
    ...         "Frequency-Modulated Continuous-Wave (FMCW) 77-GHz millimeter-wave radar "
    ...         "maintained 94.2% obstacle detection accuracy through particulate smoke densities "
    ...         "up to 120 mg/m3 at temperatures up to 250C, with a maximum ranging error of +-3.5 cm at 15 meters."
    ...     ),
    ...     metadata={
    ...         "authors": "Li et al.",
    ...         "year": "2023",
    ...         "section_title": "Sec IV-B",
    ...         "filename": "documents/Li_2023_IEEE_Sensors.pdf",
    ...     },
    ... )
    >>> rag = getattr(service_registry, "rag_service", None)
    >>> if rag and getattr(rag, "embeddings", None):
    ...     vecs = rag.embeddings.embed_documents([c_radar.text_content])
    ...     c_radar.embedding, c_radar.in_vector_index = vecs[0], True
    ...     c_radar.save(update_fields=["embedding", "in_vector_index"])

Execution
---------
We run the parent compound blueprint **live** against the active model.

    >>> prompt = "Design an obstacle detection sensor payload for autonomous indoor firefighting robots."
    >>> conv = Conversation.objects.create(
    ...     user=user,
    ...     title="Compound Sensor Investigation",
    ...     state_tree={"macro_objective": prompt, "established_facts": []}
    ... )

    >>> with contextlib.redirect_stdout(io.StringIO()) as captured_out:
    ...     result = run_blueprint(parent_bp.id, prompt, conversation_id=str(conv.id), user_id=user.id)
    >>> result["stdout"] = captured_out.getvalue()

    >>> monologue = result.get("internal_monologue", [])
    >>> step_names = [m.get("step_name") for m in monologue]
    >>> sub_entries = [m for m in monologue if m.get("step_name") == "Delegate Evidence Extraction"]
    >>> sub_mono = sub_entries[0].get("sub_monologue", []) if sub_entries else []
    >>> final_resp = str(result.get("final_response", ""))
    >>> facts = (result.get("state_tree", {}) or {}).get("established_facts", [])
    >>> has_untruncated_fact = bool(facts) and "[truncated]" not in facts[0]
    >>> expected_outcome = (
    ...     "Delegate to Evidence Extractor child blueprint, bubble untruncated cited Li et al. (2023) "
    ...     "77-GHz radar findings (94.2%, 250C, +-3.5 cm) into state_tree['established_facts'], "
    ...     "and synthesize a grounded firefighting robot sensor recommendation."
    ... )
    >>> checks = [
    ...     {"label": "sub-blueprint executed with nested trace", "passed": len(sub_mono) >= 2, "detail": f"sub_steps={len(sub_mono)}"},
    ...     {"label": "established_facts accumulated without truncation", "passed": has_untruncated_fact, "detail": str(facts[:1])[:120]},
    ...     {"label": "final recommendation cites Li et al. or 77-GHz radar", "passed": "li et al" in final_resp.lower() or "77-ghz" in final_resp.lower() or "fmcw" in final_resp.lower(), "detail": ""},
    ... ]
    >>> report_doctest_run("11. compound_evidence_investigation", prompt, result, expected_outcome=expected_outcome, checks=checks)

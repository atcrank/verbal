============================================
Trial 6: Large Output Handling
============================================

This test verifies the agent's ability to handle large data without crashing the context window
and outputting an analysis based on a generated dataset.

    >>> import contextlib, io, sys
    >>> import uuid
    >>> from llm_api.models import User
    >>> from metacognition.models import CognitiveBlueprint
    >>> from metacognition.tasks import run_blueprint

Set up the test and select the Blueprint to run:    
    >>> user, _ = User.objects.get_or_create(username="test_user", defaults={"is_staff": True, "is_superuser": True})
    >>> if not (user.is_staff and user.is_superuser):
    ...     user.is_staff = True
    ...     user.is_superuser = True
    ...     user.save(update_fields=["is_staff", "is_superuser"])
    >>> bp = CognitiveBlueprint.objects.filter(name__startswith="Escalation of Effort").first()
    >>> cid = str(uuid.uuid4())
    >>> from llm_api.models import Conversation
    >>> _ = Conversation.objects.create(id=cid, user=user)

The User prompt is as follows:
    >>> prompt = (
    ...     "Write a Python script to generate a synthetic dataset (employees.csv) of 1000 fictional "
    ...     "employees (Name, Department, Salary, Performance Score) and save it. "
    ...     "Then, use a second script to read this CSV and output a statistical summary (mean salary per department). "
    ...     "Finally, provide a verbal interpretation of those statistics."
    ... )

We then execute the Blueprint, redirecting its output to "captured_out" and capture the result:
    >>> with contextlib.redirect_stdout(io.StringIO()) as captured_out:
    ...     result = run_blueprint(bp.id, prompt, conversation_id=cid, user_id=user.id)
    
    >>> if result:
    ...     import os
    ...     result["stdout"] = captured_out.getvalue()
    ...     conv_ws = Conversation.objects.get(id=cid).get_workspace_dir()
    ...     csv_path = os.path.join(conv_ws, "employees.csv")
    ...     csv_exists = os.path.exists(csv_path)
    ...     csv_text = open(csv_path, encoding="utf-8", errors="replace").read() if csv_exists else ""
    ...     row_count = max(0, len([ln for ln in csv_text.splitlines() if ln.strip()]) - 1) if csv_exists else 0
    ...     no_ellipsis = "Ellipsis" not in csv_text and "..." not in csv_text
    ...     final_str = str(result.get("final_response", ""))
    ...     no_raw_tool_dump = (
    ...         "tool_code" not in final_str
    ...         and '"tool_calls"' not in final_str
    ...         and not final_str.startswith("ABORTED:")
    ...     )
    ...     expected_outcome = (
    ...         "Generate employees.csv with 1000 valid non-placeholder rows (no Ellipsis), compute mean salary "
    ...         "per department in a follow-up Python script, and present concise verbal summary statistics (<5000 chars)."
    ...     )
    ...     checks = [
    ...         {"label": "employees.csv created with ~1000 valid rows (no Ellipsis)", "passed": csv_exists and 900 <= row_count <= 1100 and no_ellipsis, "detail": f"exists={csv_exists}, rows={row_count}, no_ellipsis={no_ellipsis}"},
    ...         {"label": "clean verbal synthesis without raw tool/code dumps", "passed": no_raw_tool_dump, "detail": f"len={len(final_str)}"},
    ...     ]
    ...     report_doctest_run("6. large_output", [prompt], result, expected_outcome=expected_outcome, checks=checks)

Evaluate the result for pytest:
    >>> assert "error" not in result, f"Execution failed: {result.get('error')}"
    >>> assert result.get("final_response") != "No output.", "No response generated."
    >>> assert len(result.get("internal_monologue", [])) > 0, "Execution produced empty monologue."
    >>> # Ensure the agent didn't just dump all 1000 names into the final response
    >>> assert len(result.get("final_response", "")) < 5000, "Response is too large, agent dumped the raw data."

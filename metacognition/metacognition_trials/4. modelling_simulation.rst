Scenario 1.4: Complex Modeling and Simulation
=============================================

This scenario tests the AI's ability to translate a real-world problem into a mathematical model,
write a simulation script, execute it, and analyze the results. This represents a "threshold" case
that often requires multiple iterations of planning, coding, and debugging arrays.

Execution
---------
We target the full agentic pipeline.

    >>> from metacognition.tasks import run_blueprint
    >>> from metacognition.models import CognitiveBlueprint
    >>> from django.contrib.auth.models import User
    >>> user, _ = User.objects.get_or_create(username="test_user", defaults={"is_staff": True, "is_superuser": True})
    >>> if not (user.is_staff and user.is_superuser):
    ...     user.is_staff = True
    ...     user.is_superuser = True
    ...     user.save(update_fields=["is_staff", "is_superuser"])
    >>> bp = CognitiveBlueprint.objects.filter(name__startswith="ResearchEvaluation").first()

    >>> prompt = (
    ...     "I need to model a predator-prey ecosystem over 100 months using the Lotka-Volterra equations. "
    ...     "The initial population of Rabbits (prey) is 40. Their natural birth rate is 0.1, and the rate at which they are eaten is 0.02. "
    ...     "The initial population of Foxes (predators) is 9. Their growth rate from eating rabbits is 0.01, and their natural death rate is 0.1. "
    ...     "Write a Python script using numpy to simulate this ecosystem using the Euler method with a time step of dt=1 month for 100 steps. "
    ...     "Analyze the results to find the peak population of Rabbits and the peak population of Foxes. "
    ...     "Execute the script and return those two peak values."
    ... )

    >>> import contextlib, io, re
    >>> with contextlib.redirect_stdout(io.StringIO()) as captured_out:
    ...     result = run_blueprint(bp.id, prompt, user_id=user.id)
    >>> result["stdout"] = captured_out.getvalue()

    >>> expected_outcome = (
    ...     "Write and execute an Euler integration Python script (dt=1, 100 steps, R0=40, F0=9, "
    ...     "alpha=0.1, beta=0.02, delta=0.01, gamma=0.1). True Euler peaks are Peak Rabbits ~67.07 "
    ...     "and Peak Foxes ~37.73 (distinct from the initial t=0 counts of 40 and 9)."
    ... )
    >>> final_str = result.get("final_response", "")
    >>> monologue = result.get("internal_monologue", [])
    >>> ran_sandbox = any("Sandbox Execution Succeeded" in str(m.get("tool_result", "")) or "Sandbox Execution Succeeded" in str(m.get("output", "")) for m in monologue)
    >>> nums = [float(x) for x in re.findall(r"\b\d+(?:\.\d+)?\b", final_str)]
    >>> has_r_peak = any(65.0 <= n <= 69.0 for n in nums)
    >>> has_f_peak = any(36.0 <= n <= 39.5 for n in nums)
    >>> checks = [
    ...     {"label": "sandbox Euler script executed (RC=0)", "passed": ran_sandbox, "detail": "python_sandbox output recorded"},
    ...     {"label": "peak rabbits near 67.07 (not initial 40)", "passed": has_r_peak, "detail": f"numbers found: {nums[:10]}"},
    ...     {"label": "peak foxes near 37.73 (not initial 9)", "passed": has_f_peak, "detail": f"numbers found: {nums[:10]}"},
    ... ]
    >>> report_doctest_run("4. modelling_simulation", prompt, result, expected_outcome=expected_outcome, checks=checks)

    >>> assert "error" not in result, f"Execution failed: {result.get('error')}"
    >>> assert len(monologue) > 0 and bool(final_str), "Blueprint produced empty output"
    >>> print(f"- complete attempt: {1 if final_str else 0}/1")
    - complete attempt: 1/1

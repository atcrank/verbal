Scenario 13: Multimodal Visual Evidence and Empirical Chart Reasoning
======================================================================

This trial demonstrates the canonical ``Visual Evidence Investigator`` blueprint.
It highlights:
1. **Deterministic Multimodal Retrieval (``pure_tool``)**: Step 1 executes ``document_reader`` to retrieve candidate literature passages and figure chunks without invoking the LLM, burning 0 LLM tokens and achieving immediate zero-inference retrieval.
2. **On-Demand Visual Inspection (``inspect_chart_image``)**: Step 2 examines the retrieved chunks. Noting a figure chunk with an associated image asset (``Type: Visual Figure``), the agent detects that precise numerical coordinates are needed and calls ``inspect_chart_image`` on the image asset.
3. **Empirical Synthesis with Authoritative Citations**: Combines the qualitative textual context with exact numerical measurements extracted from the chart plots, attaching an academic citation header: ``[Author (Year) — Figure N]``.

Execution (Hybrid Live / Conditional VLM Mock)
----------------------------------------------
All blueprint reasoning steps run **live** against the active model; only ``inspect_chart_image`` VLM coordinate extraction is conditionally mocked if the active model is strictly text-only.

    >>> prompt = (
    ...     "What is the exact ranging error of the 77-GHz FMCW radar and 3D LiDAR at 200C and 250C "
    ...     "according to the empirical plot in Figure 4 of Talavera et al. (2023)?"
    ... )

    ...     "plot_type": "line_plot",

Proactive Night Manager
=======================

This trial tests the ability of the NightManager to proactively review the server state and log its findings using the WS7 State Tree architecture.

First, we set up the environment and define a dummy user prompt that would simulate the periodic schedule triggering the NightManager.
The NightManager's instructions execute a 4-phase autonomous pipeline:
1. Phase 0 (Housekeeping): Execute deterministic tasks (document ingestions, Grips digestion, database backup, system janitor).
2. Phase 1 (Deep System Evaluation): Evaluate conversation logs, benchmark trends, RAG efficiency, and Grips structure.
3. Phase 2 (System Modifications): Revise ReasoningStep variants, adjust ReadingStrategies, expand Grips, and queue benchmarks.
4. Phase 3 (Meta-Self Reflection): Review overall performance and propose an updated NightManager Blueprint definition.

    >>> from metacognition.tasks import run_blueprint
    >>> import contextlib

    >>> 
    >>> # Trap standard output so the test doesn't fail due to verbose logging
    >>> f = io.StringIO()
    >>> prompt = (
    ...     "You are the NightManager, an autonomous system maintenance administrator. "
    ...     "Perform your multi-phase nightly review: "
    ...     "1) Run housekeeping tasks (ingestion sweep, Grips digestion & linting, DB backup, workspace janitor); "
    ...     "2) Evaluate conversation logs, reasoning step variants, and benchmarks, looking at RAG efficiency, Grips recall and precision; "
    ...     "3a) Consider and propose reasoning step variants for performance improvements"
    ...     "3b) propose Grips knowledge expansions with new Domains or ConceptNodes where ready knowledge would have been helpful; "
    ...     "3c) consider and propose new ReadingStrategies for better chunking and retrieval;"
    ...     "3d) select or design appropriate benchmarking for the amendments and queue benchmarks for execution;"
    ...     "5) Perform meta-self reflection and report your findings."
    ... )
    >>> 
    >>> # Mock database_backup to prevent dumpdata inside test transactions

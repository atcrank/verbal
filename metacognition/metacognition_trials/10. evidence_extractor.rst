Scenario 10: Deterministic Evidence Extraction and Empirical Sifting
===================================================================

This trial executes the canonical ``Evidence Extractor`` blueprint **live** against seeded database chunks:
1. **Deterministic Retrieval (``pure_tool``)**: Step 1 runs ``document_reader`` without invoking the LLM, retrieving candidate chunks into ``scratch["raw_retrieval_chunks"]``.
2. **Empirical Distillation (``llm``)**: Step 2 runs live inference over the retrieved chunks, sifting distracting definitions and extracting the empirical measurement with an academic citation.

Setup & Database Seeding
------------------------
We initialize ``Evidence Extractor`` and seed real ``RAGChunk`` rows (embedded cleanly if vector search is active).

    >>> from django.contrib.auth.models import User
    >>> from background_resources.models import RAGChunk
    >>> from llm_api.apps import service_registry
    >>> from metacognition.models import CognitiveBlueprint, ReasoningStep, ToolDefinition
    >>> from metacognition.seed import seed_evidence_extractor, seed_tools
    >>> from metacognition.tasks import run_blueprint
    >>> import contextlib, io

    >>> user, _ = User.objects.get_or_create(username="evidence_trial_user")
    >>> seed_tools(ToolDefinition)
    >>> seed_evidence_extractor(CognitiveBlueprint, ReasoningStep, ToolDefinition)
    >>> bp = CognitiveBlueprint.objects.get(name="Evidence Extractor")

Seeding Literature Chunks
-------------------------
We store two ``RAGChunk`` entries in Postgres: a generic definition distractor and a quantitative IEEE radar paper excerpt.

    >>> _ = RAGChunk.objects.filter(chunk_id__in=["trial10-noise", "trial10-empirical"]).delete()
    >>> c_noise = RAGChunk.objects.create(
    ...     chunk_id="trial10-noise",
    ...     text_content=(
    ...         "Sensors are physical devices converting stimuli to electrical signals. "
    ...         "In firefighting, standard NFPA equipment guidelines should be reviewed regularly."
    ...     ),
    ...     metadata={"citation": "FirefightingGlossary.txt", "filename": "documents/FirefightingGlossary.txt"},
    ... )
    >>> c_emp = RAGChunk.objects.create(
    ...     chunk_id="trial10-empirical",
    ...     text_content=(
    ...         "Frequency-Modulated Continuous-Wave (FMCW) 77-GHz millimeter-wave radar "
    ...         "maintained 94.2% obstacle detection accuracy through particulate smoke densities "
    ...         "up to 120 mg/m3 at temperatures up to 250C, with a maximum ranging error of +-3.5 cm at 15 meters."
    ...     ),
    ...     metadata={
    ...         "authors": "Li et al.",
    ...         "year": "2023",
    ...         "section_title": "Sec IV-B",
    ...         "filename": "documents/Li_2023_IEEE_Sensors.pdf",
    ...     },
    ... )
    >>> rag = getattr(service_registry, "rag_service", None)
    >>> if rag and getattr(rag, "embeddings", None):
    ...     vecs = rag.embeddings.embed_documents([c_noise.text_content, c_emp.text_content])
    ...     c_noise.embedding, c_noise.in_vector_index = vecs[0], True
    ...     c_emp.embedding, c_emp.in_vector_index = vecs[1], True
    ...     c_noise.save(update_fields=["embedding", "in_vector_index"])
    ...     c_emp.save(update_fields=["embedding", "in_vector_index"])

Execution
---------
We invoke ``Evidence Extractor`` live with a technical question on 77-GHz radar in smoke.

    >>> prompt = (
    ...     "What is the measured obstacle detection accuracy and ranging precision of "
    ...     "77-GHz radar in thick particulate smoke at high temperatures?"
    ... )

    >>> with contextlib.redirect_stdout(io.StringIO()) as captured_out:
    ...     result = run_blueprint(bp.id, prompt, user_id=user.id)
    >>> result["stdout"] = captured_out.getvalue()

    >>> expected_outcome = (
    ...     "Retrieve the Li et al. (2023) empirical excerpt (bypassing glossary fluff) and extract "
    ...     "94.2% accuracy, 120 mg/m3 smoke, 250C temperature, and +-3.5 cm ranging error at 15 m with citation."
    ... )
    >>> final_resp = str(result.get("final_response", ""))
    >>> checks = [
    ...     {"label": "deterministic pure_tool retrieval ran", "passed": "Deterministic Tool Executor" in str(result.get("internal_monologue", [{}])[0].get("system_prompt", "")), "detail": ""},
    ...     {"label": "extracted 94.2% accuracy and +-3.5 cm", "passed": "94.2" in final_resp and "3.5" in final_resp, "detail": ""},
    ...     {"label": "included Li et al. (2023) citation", "passed": "li et al" in final_resp.lower() or "2023" in final_resp, "detail": ""},
    ... ]
    >>> report_doctest_run("10. evidence_extractor", prompt, result, expected_outcome=expected_outcome, checks=checks)

Scenario 12: In-the-Wild Evidence Extraction from Real Uncurated Literature
=============================================================================

This trial evaluates the canonical ``Evidence Extractor`` blueprint against the
unvarnished chaos of real-world literature from the project's active corpus.

Unlike synthetic trials with clean, isolated 40-word paragraphs, this trial tests
the small local model (Gemma 4 E2B) against authentic document chunks containing:
1. **The Glossary Trap**: Shallow dictionary definitions from ``FirefightingGlossary.txt``.
2. **The Urbanization Trap**: Broad introductory background fluff from ``Li et al. 2023``.
3. **The Real Field Trial Chunk**: Dense experimental data from ``Talavera et al. 2023`` featuring OCR quirks (``∘ 16.31 C``, ``m 2``, ``eCO 2``), embedded URLs, and simulation notes alongside real physical parameters (``2.07 kg``, ``9 h 36 min``).
4. **The Negative Inquiry (Absence Test)**: Testing whether the model reliably outputs *"No empirical evidence found in corpus"* when asked for a specification (submerged sonar depth) completely absent from the retrieved literature (``Penders et al. 2011``), rather than hallucinating plausible figures.

Execution: Multi-Turn Live Evaluation
-------------------------------------
Turn 1 tests empirical parameter sifting amidst glossary and preamble clutter.
Turn 2 executes an adversarial negative inquiry on warehouse firefighting (testing absence of submerged sonar evidence).

    >>> prompt_empirical = (
    ...     "What is the verified operating autonomy and robot weight with payload measured during real interventions?"
    ... )
    >>> prompt_negative = (
    ...     "What is the submerged underwater acoustic sonar ranging accuracy and maximum operating depth of the warehouse firefighting robot swarm?"
    ... )

    >>> conv = Conversation.objects.create(
    ...     user=user,
    ...     title="Wild Corpus Evidence Ingest",
    ...     state_tree={"macro_objective": "Evaluate empirical extraction from real literature", "established_facts": []}
    ... )
    >>> cid = str(conv.id)
    >>> prompts = [prompt_empirical, prompt_negative]

    >>> results = []
    >>> with contextlib.redirect_stdout(io.StringIO()) as captured_out:
    ...     for p in prompts:
    ...         res = run_blueprint(bp.id, p, conversation_id=cid, user_id=user.id)
    ...         cid = res.get("conversation_id")
    ...         results.append(res)

    >>> combined_result = dict(results[1])
    >>> combined_result["internal_monologue"] = results[0].get("internal_monologue", []) + results[1].get("internal_monologue", [])
    >>> combined_result["turn_responses"] = [results[0].get("final_response", ""), results[1].get("final_response", "")]
    >>> combined_result["stdout"] = captured_out.getvalue()

    >>> resp1 = results[0].get("final_response", "")
    >>> resp2 = results[1].get("final_response", "")

---
name: spec-driven-development
description: Draft a plan before writing any new code for a feature.
---
When this skill is invoked:
1. Analyze the requested feature and the current Django project structure.
2. Identify which apps (services) will be affected (e.g., experiment design, metacognition).
3. Ask questions of the user to clarify areas of uncertainty.
4. Devise the API and high-level additional tests that these changes must pass, and identify any tests or features to be removed.
5. Create a clear plan describing the end state with examples and the pathway to take.
6. Wait for user approval before generating any code.
